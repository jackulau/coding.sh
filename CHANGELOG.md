# Changelog

All notable changes to coding.sh are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions will
follow [Semantic Versioning](https://semver.org/) from the first npm release.

Each release opens with a short summary. The list under it has one line per change,
grouped by area, with links to the docs for the details.

## [0.1.7] - Unreleased

### Added

- **CLI.** Three days after first use, a successful command prints one dim line asking for a GitHub star, and `coding.sh ui` shows a small card after 5 sessions. The line prints once; the card shows until you dismiss it or click Star. Neither makes a network call. `CODING_SH_NO_STAR_PROMPT=1` turns both off. [Install](https://github.com/jackulau/coding.sh/blob/main/docs/guides/install.md#updates)
- **Checks.** `npm run gate` runs every pre-commit check in one pass under a throwaway home: repo hygiene, branch freshness, lint, actionlint, generated files, build and tests, store plugins, the Python SDK, the site, a secret scan and adapter versions. A failing step prints the command that reruns it. [Contributing](https://github.com/jackulau/coding.sh/blob/main/CONTRIBUTING.md)
- **Lint.** New rules: vendor-literal, site-voice, universal-transition, reduced-motion, global-install and personal-data. `slop.mjs --strict-allowlist` fails on allowlist entries that no longer match anything. [Contributing](https://github.com/jackulau/coding.sh/blob/main/CONTRIBUTING.md)
- **Doctor.** `coding.sh doctor` counts recent model calls past a physical limit (speed, time to first token, duration) and names the session with the most. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md)
- **SDK.** `coding_sh.weights_edit()` in the Python SDK records each weight edit a script makes as one `notification` event with `payload.kind: "weights.edit"`: tensor name, shape, weights changed, L2 and max-abs of the change, and the base and edited sha256. It adds no event kind, and `coding_sh.weights_delta()` computes the counts and norms for small arrays without numpy. [Docs](https://coding.sh/docs/api)
- **Evals.** `coding.sh exp compare A B --given <grader>` compares only the cases where that grader passes in both runs, and prints how many it kept and dropped. With a `terminated` grader this separates "finished more answers" from "got more of the finished answers right". [Compare an edited model with its base](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#compare-an-edited-model-with-its-base)
- **MCP.** In 2026-07-28 requests, list, read and discover results carry `ttlMs` and `cacheScope`: the tool, prompt and template lists are cached for an hour, `server/discover` for five minutes, and sessions are not cached. [MCP server](https://coding.sh/docs/mcp#protocol)

### Changed

- **Docs.** The docs home, the home page FAQ and llms.txt say what coding.sh does: it records prompts, model calls, tool calls, file changes and cost, shows each run in a local viewer, and turns failed runs into evals. Other products are named only on the compare pages and where they are an integration, and a site test enforces it. [Docs](https://coding.sh/docs)
- **Docs.** `--help`, the package descriptions, the README, the site's description and llms.txt say what coding.sh records instead of "open-source, local-first observability and evals for any AI agent", and the site's status line shows the current release (it said v0.1.4). A site test fails on stacked category words in published text. [Docs](https://coding.sh/docs)
- **Node.** The minimum Node is 22.16, because 22.15 has no SQLite FTS5. A store that lacks FTS5 now fails with reason `no_fts5` and names Node 22.16. CI runs the packed CLI on Node 22.16.0. [Install](https://github.com/jackulau/coding.sh/blob/main/docs/guides/install.md)
- **CI.** New jobs: the static gate, the Postgres store, the Python SDK on 3.9 and 3.13, and the release smoke test. The site job fails instead of skipping when its build is missing. [Contributing](https://github.com/jackulau/coding.sh/blob/main/CONTRIBUTING.md)
- **Stats.** `stats` rolls each subagent's cost, tokens and tool calls into its top-level session. [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md)
- **Experiments.** `exp compare --gate` says "Don't ship" only when B's losses beat chance, by an exact one-sided binomial test on the cases that changed outcome. Losses within that noise hold. Each group under `--by` keeps the old rule, as refine's guard set does. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **CLI.** A JSON error's `next` is always a label and a command. A suggestion that needs the user's approval is labelled "With their approval:". Next-step hints shell-quote the names you typed and print full session ids. [API](https://github.com/jackulau/coding.sh/blob/main/docs/reference/api.md)
- **Evals.** `judge grade` exits 2 with reason `grader_error` when the grader could not run, so a verifier can tell it apart from a fail verdict (exit 1). [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md)
- **Docs.** The docs are regrouped by task, with a quickstart for your agent or a coding agent, a first eval that ends with a fix, TypeScript and Python tabs, viewer screenshots, and Copy page and View as Markdown on every page. New pages cover cost, the query language, LLM judges, eval methods, deploying the server, privacy and the roadmap. [Docs](https://coding.sh/docs)
- **Docs.** The README has a quickstart in three steps, a table of what you get with the detail folded under each area, and an agents table with what each status means. The CLI README lists every command, including `statusline`, `tree`, `replay`, `blame` and `sql`, and each package README links its docs. See the [README](https://github.com/jackulau/coding.sh/blob/main/README.md).
- **Site.** Docs pages no longer jump when the web fonts load on a phone: layout shift on /docs/cli fell from 0.208 to 0.0003 and on /docs/quickstart from 0.009 to 0.0002. Desktop screens get home screenshots sized to their slot, 1.6 kB less. [Site speed](https://github.com/jackulau/coding.sh/blob/main/docs/perf.md#font-swap-and-image-sizes)
- **Site.** The edge answers moved URLs with permanent redirects, keeps a page prefetched on hover for the click, caches hashed images and search files for a year, compresses the changelog feed, and names the page as canonical on each Markdown copy. [Site speed](https://github.com/jackulau/coding.sh/blob/main/docs/perf.md#font-swap-and-image-sizes)
- **Agent text.** llms.txt lists the blog and links every CLI command. llms-full.txt leaves out the per-version changelog pages and the per-command CLI pages (647 kB, was 1,046 kB), and each Markdown copy's `updated:` is its page's last change. [llms.txt](https://coding.sh/llms.txt)

### Fixed

- **MCP.** A request cancelled with `notifications/cancelled` gets no reply (a cancel for `initialize` is ignored), a cursor on `tools/list`, `prompts/list` or `resources/templates/list` is an error, a request with a null id gets an error instead of no answer (a null-id `notifications/` message is still a notification), and a 2025-03-26 session accepts batches. [MCP server](https://coding.sh/docs/mcp#protocol)
- **MCP.** Tool answers stay under 25,000 characters. A tool that pages returns `nextCursor`; the others return fewer rows with `limitUsed`. `session_replay` pages its files, cuts diff and file text that does not fit and says so with `truncated` (a range was 5 million characters). `benchmarks` has a default limit. [MCP server](https://coding.sh/docs/mcp#tools)
- **MCP.** `eval_init` and `score_add` are marked destructive, since both can replace stored data, and `score_list`'s error names its `since` argument instead of the CLI's `--since`. [MCP server](https://coding.sh/docs/mcp#tools)
- **Site.** The changelog and quickstart pages no longer shift on a phone while loading: release area chips sit in a fixed grid and the quickstart tab list is laid out from first paint. Layout shift fell from 0.052 to 0 and from 0.023 to 0. [Site speed](https://github.com/jackulau/coding.sh/blob/main/docs/perf.md#font-swap-and-image-sizes)
- **Stores.** A `file:///C:/...` blob URL and a `sqlite://user:password@/path` index URL open the path they name on Windows, and the user and password are no longer read as a folder. See [stores](https://github.com/jackulau/coding.sh/blob/main/docs/reference/stores.md).
- **Capture.** Model calls no longer show impossible speeds such as 3750 tok/s. A hook reading a transcript from mid-response, or late Codex lines, gave a call a start time inside the response; such a call now has no duration, time to first token or speed. A Claude Code call gets them back when the import reads the whole transcript. [Adapters](https://github.com/jackulau/coding.sh/blob/main/docs/ADAPTERS.md#known-breakage-to-design-around)
- **Tests.** The viewer's browser tests no longer hang when Chrome drops its DevTools connection: a waiting call fails at once, and any call fails after 30 s. The helper lets go of Chrome's pipe after closing it, and the CI runner ends each test file once its tests finish, so an open handle cannot hold a Windows job. [Contributing](https://github.com/jackulau/coding.sh/blob/main/CONTRIBUTING.md)
- **Capture.** A blob store outage no longer drops spool events while the cursor moves on, and a full disk no longer leaves a torn spool line or loses the whole line `hook.sh` appends after one. Ingest redacts short payloads inside the spool file once their day has passed. A session run with `CODING_SH_DISABLE=1` no longer comes back through backfill. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md)
- **Doctor.** `doctor` reports a missing `hook.sh`, a spool file hooks cannot write and recent failed hook writes. `doctor` and `status` mask the password in a store URL. `init` exits 0 when only an agent's setup failed, and `init --dry-run` lists the bin files it would write. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md)
- **Init.** `init` registers no MCP server for an agent whose hooks it could not install, so a failed agent is left as it was. [Install](https://github.com/jackulau/coding.sh/blob/main/docs/guides/install.md)
- **Stores.** `error:` matches an error event's message, a quoted `*` is a wildcard and `\*` a literal star, and the Postgres and ClickHouse stores compile `--where` as SQLite does. Concurrent `dataset add` runs merge instead of losing a version. An empty dataset import exits 1. [Query](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md)
- **Stores.** The index, its WAL files, blob packs and backups are written owner-only (0600), and new store folders 0700. On the SQLite store, a search of only emoji or symbols finds matches. `upgrade-store` on a plugin store says there is nothing to upgrade. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md)
- **Stores.** `tree`, `cache doctor` and `diff-calls` on a `--store` file that does not exist stop with `store_missing` instead of creating an empty index. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md)
- **Sessions.** A prefix of a parent session opens the parent, not one of its subagents. A bare agent id or an SDK id without its project opens that session. `latest` skips empty sessions and resolves an agent run under `coding.sh run` to its wrapper. Terminal tables keep session ids whole. [CLI](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md)
- **CLI.** Impossible dates such as 2026-11-31 are refused, `diff` prints call times in local time, `show` prints the end of a failed tool's full output, and `sessions` counts what it hid. `config get` and `config set` know every documented key, and `config set` prints the old value. [CLI](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md)
- **Cache.** `cache doctor` keeps its priced total and counts breaks on an unpriced model apart. [CLI](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md)
- **Evals.** `toolevals` drivers honor ANTHROPIC_BASE_URL and OPENAI_BASE_URL, `judge calibrate` counts labels on case targets, `eval export` and `eval import` work across two homes, and `eval init --cases` works from a subdirectory. Task sandboxes no longer inherit `type: module` from a parent package.json. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Scores.** `score add` keeps an earlier comment when you leave it out and the value is unchanged. It refuses a run that does not exist and experiment targets, each with a next step. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Experiments.** `exp ab` gives each arm only the files the session's agent loads, and an edit that agent does not load stops with "No arm difference" before any model call. `exp show latest` works, and an HTTP 529 reads "overloaded". [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Bench.** A pair with over 10% of cases excluded says "no verdict" and why, and an interrupted run names the exact `--resume` command. [Benchmarks](https://github.com/jackulau/coding.sh/blob/main/docs/guides/benchmarks.md)
- **Improve.** Fix lines go to the file the flagged sessions' agent reads and name the test command it uses. [Improve](https://github.com/jackulau/coding.sh/blob/main/docs/guides/improve.md)
- **Workflows.** A run folder copied under a second session is imported once, and agents silent for 15 minutes show as stalled. [Workflows](https://github.com/jackulau/coding.sh/blob/main/docs/guides/workflows.md)
- **Serve.** `serve` honors the `[proxy]` section of `--config`, the collector refuses a host other than loopback, and the proxy rejects bad upstream URLs. [Production](https://github.com/jackulau/coding.sh/blob/main/docs/PRODUCTION.md)
- **SDK.** `require()` of the TypeScript SDK works, and both SDKs warn once on a bad collector URL. [SDK](https://github.com/jackulau/coding.sh/blob/main/docs/reference/sdk.md)
- **Viewer.** The live header refreshes in place, empty fields no longer show "null", server-rendered rows match the page's, and an unknown session id costs one request. [Explore](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md)
- **Packaging.** The published package.json no longer has `source` export conditions that point at files the tarball does not hold. `smoke.sh` runs under a throwaway home, and the GitHub Action has an `annotate` input. [Release](https://github.com/jackulau/coding.sh/blob/main/docs/RELEASE.md)
- **Site.** The docs sidebar and the phone menu open on the current page, and the phone menu fits the screen. A terminal block no longer touches the paragraph above it, wide code blocks scroll by keyboard, code copy selects the code when the browser blocks the clipboard, and search results open without a redirect. [Docs](https://coding.sh/docs)
- **Site.** Changelog notes link docs to their page on the site instead of showing raw Markdown or going to GitHub, and the changelog counts only shipped releases. [Changelog](https://coding.sh/changelog)
- **Site.** Search snippets end on a whole word, structured data resolves on every page, sitemap dates follow each page's last change, and pages no longer carry hidden text for agents. The site build now fails on each of these. [Site](https://coding.sh/)
- **Site.** The skip link opens below the header, one Tab press crosses the agent logo row, the footer links sit in rows of four and three on a phone, and a long word wraps instead of widening the page. [Site](https://coding.sh/)

## [0.1.6] - 2026-11-11

### Added

- **Privacy.** `CODING_SH_PURGE_WAIT_MS` sets how long `purge` waits for another process's read of the index or the blob pack before it says which file still holds the old bytes. The defaults stay 10 s before the VACUUM and 5 s after it. [Configuration](https://github.com/jackulau/coding.sh/blob/main/docs/reference/config.md#paths-and-stores).
- **Trace format.** A JSON Schema (draft 2020-12) for `AgentEvent` and `Session`, generated from the TypeScript types, ships as `coding.sh/schema.json` and is served at https://coding.sh/schema.json. Every adapter and OTLP fixture validates against it. [Trace format](https://coding.sh/docs/trace-format#json-schema)
- **Serve.** `CODING_SH_FORWARD_URL` (or `[serve.forward]`) makes `coding.sh serve` forward every trace it commits to an OTLP/HTTP collector, with the same trace and span ids plus `coding_sh.project`. Native batches go out as `invoke_agent`, `execute_tool` and `chat` spans. Metadata mode sends no messages, tool arguments or results; a down collector never slows ingest, spans wait in a bounded buffer, and overflow is counted in `coding_sh_forward_spans_total`. [Forward and sinks](https://github.com/jackulau/coding.sh/blob/main/docs/PRODUCTION.md#19-forward-and-sinks)
- **Sinks.** `[[sinks]]` now mirror events from the OTLP receiver (`coding.sh collector`) and from `coding.sh serve`, so a team can set one sink on serve instead of on every laptop. [Config](https://github.com/jackulau/coding.sh/blob/main/docs/reference/config.md#sinks)
- **Serve.** `createFetchHandler()` from `coding.sh/server` runs serve's ingest routes (OTLP, `/v1/ingest`, `/readyz`) as a `Request` → `Response` function for Vercel Functions, Deno, Bun or Workers. With `coding.sh-store-postgres`, several instances can write one session at once: each session rebuild takes `pg_advisory_xact_lock` on the session id. [Serverless](https://github.com/jackulau/coding.sh/blob/main/docs/production/serverless.md)
- **Evals.** Cases and tool-eval tasks take an optional `kind`: `bad` (fails before the change, passes after), `guard` or `control` (pass on both). `exp run`, `exp compare`, `toolevals run` and `toolevals compare` split results by kind and name broken controls as overcorrection, and `toolevals validate --against <variant>` reports a bad task that passes on the old variant. See [Case kinds](docs/guides/evals.md#case-kinds-bad-guard-control) and [Task kinds](docs/TOOL-EVALS.md#31-task-kinds-bad-guard-control).
- **Tool evals.** `coding.sh toolevals traces <server> --sessions 'since:30d'` (or `--from <experiment>`) prints each MCP tool's calls, errors, repeats and retries after an error, and `--out <dir>` writes the failing traces first (at most 3 passing), an `index.jsonl`, `tool-health.json` and `tools.json` for an improver to read. Held-out trials are never exported. [Tool evals](https://github.com/jackulau/coding.sh/blob/main/docs/TOOL-EVALS.md#121-toolevals-traces)
- **Tool evals.** `toolevals run --shell-model <provider/model>` has a model play the shell for a model driver on a CLI target, with a fixed date; the shell model is part of the arm name and `compare` refuses arms with different shells. [Tool evals](https://github.com/jackulau/coding.sh/blob/main/docs/TOOL-EVALS.md#42-model-driver-agent-free)
- **Tool evals.** The model driver's MCP client reads resources and prompts, counts progress notifications, runs task-augmented tool calls, answers sampling with the driver's model, elicitation with a task's scripted `[mcp]` answers and roots with the sandbox, and runs OAuth (discovery, client registration, PKCE or client credentials) on a 401. `calls` checks can match `resources/read` by uri and `prompts/get` by name. [MCP client](https://github.com/jackulau/coding.sh/blob/main/docs/TOOL-EVALS.md#10-mcp-client)
- **Tool evals.** The model driver caches the prompt on Anthropic (top-level `cache_control`; `promptCache = false` turns it off) and reads the final cache counts from the stream; the report shows cost with cache prices beside flat prices, the cache hit share, and says when the cheaper arm flips. [Tool evals](https://github.com/jackulau/coding.sh/blob/main/docs/TOOL-EVALS.md#42-model-driver-agent-free)
- **Cache.** `diff-calls` gives the line where a system prompt edit starts and the share of the prompt after it that the cache could no longer read (`system.firstChangeLine`, `system.wastedPrefixFrac` in `--json` and the viewer API). When over 20% is lost, `Why` says to move dynamic content such as timestamps to the end of the system prompt. [Capture with the proxy](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/capture-with-proxy.md#4-see-why-the-prompt-cache-missed)
- **Experiments.** `compare --signals` checks whether each session flag and tool errors predict failure beyond task difficulty: pooled, within-task and within-task-and-bundle AUROC with a task-cluster CI, beside difficulty, bundle and length references, and a verdict (`adds-run-signal`, `tracks-difficulty`, `no-signal`, `too-few-pairs`). [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#do-the-flags-predict-failure)
- **Experiments.** `exp sweep` and a matrix spec in `exp run`, with three or more configs or cells, name the plausibly best set: the configs not significantly worse than the best, by a paired-bootstrap multiple comparison with the best, which holds the truly best config 95% of the time. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#matrix)
- **Experiments.** `compare --pick N --pick-by irt` fits a Rasch (or 2PL) model on stored runs and runs first the tasks with the most information at the baseline's ability: mid difficulty, sharp discrimination. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#picking-tasks-and-a-budget)
- **Experiments.** `exp run --record` saves each case-trial's Anthropic and OpenAI calls, and `exp run --replay <EXP>` serves them again up to the first changed call (`--replay-until N` stops after call N), so a late change re-runs only the calls it touches. System-prompt and `cache_control` edits still replay; API keys are never stored; with one task, the recorded config runs as a control arm and compare prints its noise floor. See [docs/how-to/replay-llm-calls.md](docs/how-to/replay-llm-calls.md).
- **Experiments.** `exp run --seq K --feedback bit|reasons|critic=<grader>` tries a failing case-trial again with feedback on its earlier attempts, up to K attempts, and reports Seq@1..K with intervals, EGS/LGS, unchanged revisions, cost to solve and, with 2+ trials, pass@k against seq@k by cost. The pass rate stays the first attempt's; feedback never shows the expected answer; `exp compare` adds a `seq@K` row and `--verdict seq` (arXiv 2610.37859). [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#sequential-attempts-with-feedback).
- **Experiments.** `exp run --failing <EXP>`, `--errors-from`, `--case <PATTERN>`, `--sample N --seed S` and `--first-n` run part of a dataset. When B ran only on A's failures, `exp compare` warns of regression to the mean, says inconclusive and `--gate` holds until A's config runs on the same cases. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#running-a-subset-failures-samples-the-first-n).
- **Experiments.** `exp run` stores the experiment so far while it runs; after a crash `exp list` marks it `(partial)`, and `exp run … --resume <experiment>` runs only what is left (`--retry-errors` also re-runs its task errors). A resume with other graders, trials, task, dataset version or case selection is refused and names what changed. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#long-runs-resume-retries-status).
- **Experiments.** `exp sweep --guard <dataset>|prior` re-runs the start and winning configs on earlier suites and keeps the start config, exit 1, when the winner breaks more than `--guard-tau` of what the start solved there, even when the target suite ships. Shipped sweeps are remembered in `adoptions.jsonl` for `--guard prior`. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#datasets-and-experiments).
- **Experiments.** `exp compare` takes `--pairwise` more than once: it reports each judge, Cohen's κ between judges, and `replicated-better`, `judges-disagree` or `unresolved`, screens out a judge whose calibration failed, and with `--gate` holds a ship when any judge prefers A or two judges do not both find B better (arXiv 2611.04090). [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#judges).
- **Experiments.** `exp compare --labels-a --labels-b` corrects each LLM judge grader's B − A with human labels of each arm's outputs (PPI++), and warns when the judge errs differently on the two arms. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#correcting-a-judges-delta-with-human-labels).
- **Refine.** `coding.sh refine mine` ranks failure patterns across sessions with no model call: session flags, normalized error lines (20 `TS2307` errors in 5 sessions are one pattern), instructions you typed again and again, and failed eval runs, each with its count, sessions and example events, redacted. `refine propose --mined FILE` shows the top patterns to the proposer. [Mining failure patterns](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#mining-failure-patterns).
- **Refine.** `coding.sh refine diagnose` asks a model what went wrong in recent sessions and groups the answers into Signals with stable ids; `refine signals` lists them. Every problem needs a citation that code checks against the redacted trace, severity is computed by code, replies are cached so a rerun makes no call, and with no API key it prints a $0 plan of the sessions and tokens it would send. [Diagnosing sessions into Signals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#diagnosing-sessions-into-signals).
- **Refine.** `refine test|run --suite --canary-model <model>` re-tests a kept edit that deletes or rewords lines (`--canary all`: every kept edit) under a cheaper model and rejects it as `canary-regression` when the pass rate falls there; `refine recheck <r_…> --model` runs the same check later. A subtractive edit kept without a canary gets a note. Wrapper agents take a `{model}` slot in their flags. [Canary re-test](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#canary-re-test).
- **Refine.** `coding.sh refine distill` writes an experiment's runs (or recent sessions) as a redacted corpus, leaving out held-out tasks, and has Claude Code or Codex analyze it with its own code and write one skill in an isolated directory. The skill is size-capped, checked by the critics and ledgered as a proposed candidate with its provenance for `refine test`. [Distilling a skill](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#distilling-a-skill).
- **Refine.** The proposal prompt lists, per earlier edit that was not kept, the tasks it fixed, regressed and left failing, read from the ledger, and asks for lines aimed at the still-failing tasks. With no such rounds the prompt is unchanged. [Refine loop](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#refine-loop).
- **Export.** `coding.sh export --evidence <dir>` writes each matching session as a folder of files: `index.md` with stats and a timeline, `session.json`, `events.jsonl`, and one file per tool call with its input and full output. Everything is redacted first, files are size-capped, and the same store gives the same bytes. [Query and export](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md#evidence-folders).

### Changed

- **Docs.** An adapter that nobody has run on a live install is now labelled "Not run live" in the README, the agents guide and the site. Only Cursor CLI and Amp are in that state; both need an account login. [Agents](https://coding.sh/docs/agents)
- **Improve.** `improve check` says Helped only when failures fall: the flagged share, or one flag (Holm-adjusted) with no other rising significantly in its place. A new line the agent follows while flagged sessions stay put is now "Followed, no effect yet", and a change after which sessions make 1.25x the tool calls or take 1.25x as long, with no fall, is "Costlier"; both suggest `refine test git:<previous>` to test the harness without it. `--json` adds `work` and `next`. Regressed and its exit 1 are unchanged. [Improve](https://github.com/jackulau/coding.sh/blob/main/docs/guides/improve.md#did-your-last-change-help).
- **Tool evals.** The model driver's 16 KB tool-output cap is structure-aware by default: JSON stays valid and keeps every key, and logs keep whole lines; output under the cap is unchanged. `outputCap = { mode = "prefix" }` on a driver or variant brings back the old byte cut for an A/B, and the report counts cuts and broken-JSON cuts. - **Sessions.** `stats.toolErrors`, `repeated-tool-failure` and the `failure-streak` derail count only real failures. A search that found nothing (`grep`, `rg` exiting 1 with no output), a probe that answered no (`test -f`, `command -v`) and a `diff` that found differences are counted in the new `stats.benignToolErrors`, and a stopped call in `stats.interruptedToolCalls`. Stored sessions are counted again on the next ingest. [API](https://github.com/jackulau/coding.sh/blob/main/docs/reference/api.md#get-apisessionsid).
- **Sessions.** A shell command run from a REPL or code tool's cell (`bash("npm test")`, `subprocess.run(["pytest"])`, `os.system`, an IPython `!` line, a `%%bash` cell) counts as verification for `no-verification`, as the same command in a shell tool does. [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Sinks.** The otlp sink sends `gen_ai.usage.input_tokens` as the whole prompt, cache reads and writes included, as the OpenTelemetry GenAI conventions ask; it used to send only the uncached part, so backends undercounted cached calls. Cache writes move to `gen_ai.usage.cache_write.input_tokens` (the old `cache_creation.input_tokens` is still sent through 0.1.5), the uncached part is `coding_sh.usage.uncached_input_tokens`, and reported reasoning tokens are `gen_ai.usage.reasoning.output_tokens`. The OTLP receiver reads the sink's spans back to the same token counts and cost. [Export to ClickHouse](https://coding.sh/docs/stores#export-to-clickhouse-through-an-opentelemetry-collector).
- **Search.** Every search word must match a whole word, and only the last may start a longer one, so `the fix` no longer matches every word that begins with "the". Matches come best first, and a search with more than 20,000 matches lists them newest first instead of ranking them all. On a 756k-event store, `search` for "the", "voxel" and "error" answers in 34, 12 and 38 ms at p95 instead of 719, 171 and 81 ms. The Postgres and ClickHouse plugins and `--where` bare words match the same way. [CLI reference](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md#codingsh-search), [Storage](https://github.com/jackulau/coding.sh/blob/main/docs/design/architecture.md#efficiency).

On a 756k-event store, after `gc --compact`, it takes 1.38 MB per 1,000 events instead of 1.89. The upgrade builds the new search index and leaves old rows as they are; `gc --compact` empties their old copies and gives the space back. A coding.sh older than 0.1.5 refuses the upgraded index and says to upgrade. [Storage](https://github.com/jackulau/coding.sh/blob/main/docs/design/architecture.md#efficiency).
- **CLI.** `--agent`, `--tag`, `--session` and the other repeatable id flags take a comma list: `--agent claude-code,codex` is the same as `--agent claude-code --agent codex`, on `sessions`, `usage`, `search`, `export` and the rest. [CLI reference](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md).
- **Collector.** `coding.sh collector` stores concurrent requests together, in one transaction with one blob flush, and no longer keeps every source span as a blob (`--keep-raw` turns that back on; `serve` still keeps them). On the desk, 8 clients posting 61-span requests went from 1,437-3,075 to 5,585-6,865 spans/s, with request p95 from 283-613 ms to 125-155 ms. A long session per client is not faster. [Adapters](https://github.com/jackulau/coding.sh/blob/main/docs/ADAPTERS.md#hook-command).
- **Docs.** The instructions file is called AGENTS.md wherever any agent is meant: the home page, docs titles and prose, command examples, `--help` and the MCP tool descriptions. - **Query.** A date without a zone in `--since`, `--until`, `since:` and `until:` is local time: `2026-11-09` is local midnight (it was UTC midnight) and equals `2026-11-09T00:00:00`. `today` and `yesterday` work, and `until` is exclusive. `sessions`, `usage` and `stats` print the resolved window on stderr and carry `window` in `--json`. [Routing headroom](https://github.com/jackulau/coding.sh/blob/main/docs/guides/benchmarks.md)
- **Benchmarks.** The model × harness grid no longer states noise as fact. A rank reversal is listed only when the 95% interval of both pass-rate gaps excludes 0, each leave-one-model-out regret and the mean carry a 95% interval (`regretCi` and `meanRegretCi` in `--json`), no cell is starred under 20 paired cases, a bound that rounds to 0 no longer stars some cells of a 2 × 2 and not others, and the legend says the stars are per cell and not adjusted for the number of cells. [Model × harness grid](https://github.com/jackulau/coding.sh/blob/main/docs/guides/benchmarks.md)
- **Attribution.** Without snapshots (a store filled by `ingest --backfill`, or a session whose end snapshot is gone), a session is credited only for the lines its own Write, Edit and patch calls added, less the ones it later removed. Lines a person added to the file between two of the agent's edits used to be credited to the session once the agent read the file again. Sources cached by an older build are built again. [Attribute commits](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/attribute-commits.md#read-the-result)
- **Attribution.** A person's copy of a long line in another file of the same commit no longer takes the session's credit. Every file of a commit gets its same-file matches before a long line may match across files, so `blame` credits the agent's own line and shows `-` for the copy. [Attribute commits](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/attribute-commits.md#read-the-result)
- **Attribution.** A commit made on a branch that was no longer checked out when the session's end snapshot was taken got 0 lines, because an empty or unrelated snapshot diff hid the session's own edit tool calls. `coding.sh attribution` and `coding.sh blame` now take every file the session's tools named that the snapshot diff does not hold from those calls, at confidence 0.8. [Attribute commits](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/attribute-commits.md#read-the-result)
- **Compare.** `compare --parity` reads a tag whose attribute value holds a raw `>` in full, so two pages that differ after it no longer read as the same. [Page parity](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#page-parity)
- **Viewer.** "Open in playground" works for model calls in subagent and workflow-agent sessions: the request is rebuilt from the subagent's own conversation, without the calls of a subagent it started. Every such call used to answer 404 `no_request`. [API](https://github.com/jackulau/coding.sh/blob/main/docs/reference/api.md#get-apiplayground-get-apiplaygroundcallsid-post-apiplaygroundrun-post-apiplaygroundsave)
- **Docs.** The troubleshooting page lists each error reason under the exit code the CLI gives it, and the session rows example in the API reference is the real answer for the page's example session. [Errors by reason](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md#errors-by-reason), [API](https://github.com/jackulau/coding.sh/blob/main/docs/reference/api.md)

## [0.1.5] - 2026-11-09

### Added

- **Sessions.** A new flag, `unapproved-action`, marks a session where the agent ran a destructive or paid command after a user turn that did not approve it: `rm -rf` outside temp and build dirs, `git reset --hard` or `git push --force`, dropping a database, a tool's own `--yes` on a repair, reinit, migrate, delete or purge subcommand, deleting a data dir, or a known paid cloud or batch job. Asked only to "fix it", agents run the `--yes` their tool's error names. `stats.unapprovedActions` counts them, and `--where unapproved>0` lists the sessions. [Flags](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).

### Changed

- **Refine.** `refine test|run --suite` keeps a candidate whose pass rate is significantly better even when a listed objective such as cost got significantly worse, as long as the rise is within `--max-cost-rise` (default 50%, or `refine.maxCostRise` in config). It used to reject +27 to +67 pt gains because each run cost a few cents more. The verdict prints the trade, such as `+33.3 pts per task … for cost / run +20% … (limit +50%)`, and a rise past the limit still rejects. The gain must still pass the exact permutation test. [Climbing on an eval suite](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#climbing-on-an-eval-suite).
- **CLI.** An error whose next step deletes or overwrites data, cannot be undone, or spends money now says the user must approve it first, and its `--json` line has `askUser: true`. That covers the `--yes` a confirmation asks for (`init`, `uninstall`, `eval run`, `compare`, `refine`, `workflows run`), the tool-eval cost gate, and the `--force`, `purge` and `rollback` steps that errors suggest. The text no longer says "Did you mean" before a `--yes` command. Asked only to "fix it", agents ran the `--yes` an error named without asking. [Output and exit codes](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md#output-and-exit-codes).
- **Store.** A blob that compresses to under 4 KiB, such as a hook line's raw payload, is a row of one SQLite file, `blobs/pack.db`, instead of a file of its own; larger blobs stay files. On the 100k-event ingest benchmark the store takes 1.72 MB per 1,000 events instead of 5.51, and ingest runs at about 6,200 events/s instead of 1,700. Blob files written before still read, and `gc --compact` moves the small ones into the pack and removes the blob folders that leaves empty. A coding.sh older than 0.1.5 does not see packed blobs: its CLI reads sessions as usual, and its viewer shows their stored content as "not in the local store". Run `purge` with 0.1.5 or newer: an older purge leaves secrets in packed blobs, and they show again once you upgrade. Running the same purge again with 0.1.5 removes them, since it reads every packed blob. [Storage](https://github.com/jackulau/coding.sh/blob/main/docs/design/architecture.md#efficiency), [Store ingest](https://github.com/jackulau/coding.sh/blob/main/docs/perf.md#store-ingest).

### Fixed

- **Store.** A coding.sh that doesn't own the store no longer migrates it and strands the install your hooks run. The owner is the CLI `~/.coding.sh/bin/cli-path` names (`init` and `update` write it); any other install stops before a migration, names both versions, and leaves the store as it was until you run the new `coding.sh upgrade-store`, which also points the hooks at it. Upgrades in place and `coding.sh update` migrate as before. coding.sh run from a source checkout also no longer opens `~/.coding.sh` unless `CODING_SH_HOME`, `--store` or `CODING_SH_DEV_REAL_STORE=1` says to. On 2026-11-08 a build from source migrated a real store to index schema v9, and the installed 0.1.2 could not open it for 10 hours. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md#store-version-errors).
- **Sessions.** A session coding.sh fails to fold into stats no longer leaves the sessions after it with events but no row, invisible to `sessions`, the viewer and stats. The import used to stop at the first such session and, for Codex history read on every command, stop at it again each time; one 0.1.4 store had 906 Codex sessions like that. The session now gets a row tagged `fold:error`, with the error in `stats.foldError`, and the import goes on. `coding.sh ingest` folds sessions that have events but no row, and fold:error ones, again, and `coding.sh doctor` counts both. [Flags](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md), [Session stats](https://github.com/jackulau/coding.sh/blob/main/docs/reference/api.md).
- **Sessions.** A shell command named like a built-in object key (`constructor`, `toString`) no longer stops a session from being folded with `PAID[tool]?.test is not a function`. [Flags](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Sessions.** `sessions`, `show` and the viewer no longer crash with `Cannot read properties of undefined (reading 'briefs')` after another build of coding.sh worked out the same store. Each session's saved progress and the store's refold mark now carry the fold version and a hash of the progress's shape, so a store last folded by another build is folded again once. Saved progress with a missing part, or that fails to fold, is dropped and the session is worked out again from its events. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md#old-sessions-show-doubled-counts).
- **Evals.** An agent that is not logged in, or a setup step that fails, no longer counts as a task failure. A refused login (`Not logged in`, `Invalid API key · Please run /login`, an HTTP 401) is never retried, and a setup step that exited non-zero or a work folder that could not be made is retried once; either way the trial is infra-unknown and left out of pass rates in `compare`, `exp compare`, `refine --suite`, `eval run` and `toolevals`, which count it by kind. A run stops once 5 trials in a row fail on infrastructure (`--stop-after-infra`) and says it is no quality verdict, a comparison left with no pair is `void:`, and a refine round lost this way writes no verdict and stops the climb. An expired login had read as "quality held". [Long runs](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#long-runs-resume-retries-status).
- **Evals.** A few cases, tasks or prompts that all move the same way no longer pass a gate on their own. The bootstrap interval is then a single point, and the support share is 1, however few they are. `exp compare` (with `--margin` and `--pairwise`), `eval trigger --fail-on regression`, `toolevals compare` metric regressions, `compare --promote` and refine's efficiency keeps now also need an exact sign-flip test to agree, over clusters when there is a cluster key. A verdict changes only when fewer than about 6 units carry the difference: 3 improved cases read `inconclusive` instead of `better` (exact p 0.25), and one improved task no longer promotes. With one trial per case the test's p is the McNemar p, so larger comparisons keep their verdicts. JSON output gains `signFlip`, `p` or `exact` fields. [Audit](https://github.com/jackulau/coding.sh/blob/main/docs/design/stats-audit.md), [Paired comparison](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Privacy.** `purge` no longer reports success while another process (the viewer, `serve`, a `sqlite3` shell, a backup) holds a read on the index or the blob pack. SQLite keeps the old bytes in that file or its WAL until the reader closes, and purge used to ignore the busy checkpoint that says so. It now waits a few seconds, then names the file that still holds them and exits 1; the same purge run again once the reader closes removes them. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md).
- **Sessions.** `sessions --where id:<id>` and `export --where id:<id>` find a subagent's session, such as a Claude Code workflow agent's, as `show <id>` does. Both commands leave out subagents unless you pass `--subagents`, and that default hid every session the query named. A query with `id:`, `parent:`, `is:root` or `is:child` now decides that itself, so `--where is:child` lists subagents too. [Query and export](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md#filter-with---where).
- **Workflows.** A Claude Code workflow run that is still going is named by its script's `meta.name`, read from the copy of the script Claude Code keeps in the session's `workflows/scripts/` folder, instead of by its `wf_…` id. Claude Code writes the record, which held the only name coding.sh read, when the run ends. `workflows import` reads runs it stored before this fix again once. [Workflows](https://github.com/jackulau/coding.sh/blob/main/docs/design/workflows.md#21-claude-code-workflows).
- **Capture.** The hook no longer reads `.git` on session-start and prompt events, which made each of those hook calls about 3.5 ms slower than in 0.1.2 in a repo with a 1 MB `packed-refs`. Ingest takes a hook session's start commit from the reflog again, and still uses the HEAD a 0.1.3 or 0.1.4 hook recorded. `CODING_SH_NO_GIT_HEAD` has nothing left to turn off. [Architecture](https://github.com/jackulau/coding.sh/blob/main/docs/design/architecture.md#spool-the-hot-path).
- **Cost.** A Claude Code fork subagent (`subagent_type: "fork"`) no longer counts the parent's model calls again. Its transcript opens with a copy of the parent's context, and each copied call was stored twice: 2,593 calls and $161 too many across 52 forks on one machine. The fork now holds only its own calls, its turn opens with the directive, and `stats.inheritedTokens` says how much context it started with. Stored sessions are parsed again. [Subagents](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Harness A/B.** `compare` counts cache reads and writes in `tokens / run`. With prompt caching the row tracked output tokens only, so a harness that cost 40% more could read as 11% more tokens. [Harness A/B](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#harness-ab).
- **Privacy.** `coding.sh purge` no longer reports `Integrity check failed` and exits 1 after every purge. The check asked SQLite's full-text search to find an entry for every event, but events with no text, such as a session start or a model call, are never indexed. It now checks that the index is sound and holds exactly the events with text. Search was not affected. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md).
- **Harness A/B.** `compare` leaves out `time to first derail` when no run in either arm derailed, where it only repeated the session length. [Derails](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md#derails).
- **Refine.** `refine` and `exp ab` carry a skill's whole folder into each trial: its `scripts/`, `references/` and other files as well as its SKILL.md, so a skill that runs a helper script is tested with it. Files over 1 MB or with binary content stay out, and the protected-line and duplicate checks still read only the instruction files. [Refine loop](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#refine-loop).

[Workflows guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/workflows.md).
- **Workflows.** Cache hits on a Claude Code workflow resumed in the same run dir are read from the run's persisted record, since the journal writes no cache lines there. `workflows stats` showed 0 cache hits and no resume savings for a run whose record marks 11 agents cached; it now counts them and sums what they took when they ran as "resume saved", and `show` marks them "replayed on resume". - **Workflows.** `workflows show`, `stats` and the Gantt list a run's phases in the same order, by when each phase first started. - **Workflows.** `workflows import` redacts Claude Code workflow agent transcripts before it stores them, with the same capture settings as ingest and backfill (redaction, `[capture] redactPatterns`, metadata mode). [Query](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md).
- **Capture.** A vendor-shaped key whose value is plainly made up, such as AWS's sample, `sk-ant-test-…`, `csh_ik_aaaa…` or `SECRETSECRETSECRET`, is still redacted but counts as `placeholder-key` and no longer tags the session `secret:exposed`. Before, working on code with test fixtures, coding.sh's own included, flagged sessions as leaking credentials. Random-looking keys count as before. `coding.sh ingest --rebuild` re-counts sessions already stored. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md).
- **Improve.** A failed compound shell line counts against the part that failed: the one its error names, the tool whose error it is, the part `timeout` stopped, or the last part of a pipeline, and "compound command" when nothing singles one out. Before, it went under its first word, so `cat`, `for`, `sed`, `export` and even `--session` (from a line continuation) filled the list with errors from other tools, and a `cat` of a test log got the broken-setup verdict. [Improve](https://github.com/jackulau/coding.sh/blob/main/docs/guides/improve.md#see-what-to-fix-first).
- **Improve.** `improve`, `improve check` and the MCP `improve` and `harness_changes` tools redact secrets and email addresses in the prompts, error lines, commands and session titles they show. Before, an email address in a prompt or an error printed as is, because capture redaction covers secrets only. `capture.redact` takes `email` to keep addresses out of the store too. [Improve](https://github.com/jackulau/coding.sh/blob/main/docs/guides/improve.md#see-what-to-fix-first).
- **Storage.** An ingest or transcript import that stores more than 10,000 events empties the index's write-ahead log before it returns, and so does every command when it closes the index. Before, with the viewer or another command holding the index open, a full import left `index.db-wal` as large as the data it wrote (3.8 GB next to a 1.5 GB index) until a later command happened to close it last. [Architecture](https://github.com/jackulau/coding.sh/blob/main/docs/design/architecture.md#storage).
- **Proxy.** A model call that both `coding.sh proxy` and the agent's hooks or transcript logged shows once in `show`, `show --follow`, the viewer's timeline and the MCP `session_get` and `session_current` tools, as the proxy's copy with its call id, filled in with what only the other copy has. Before, each call printed twice, and MCP `latency` counted it twice. [Capture with the proxy](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/capture-with-proxy.md#3-read-a-call).
- **Proxy.** Storing a call no longer slows down as the session grows. The proxy folds only the new events into the session row, instead of every event in the session, and writes the call's blobs in one batch. Late in a 1,000-call session a call now takes 9 ms to store instead of 26 ms. A call stored as message blocks reads back in about 2 ms instead of 9 ms. `bench.mjs proxy-session` measures the write against an older build. [Capture with the proxy](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/capture-with-proxy.md).
- **Evals.** `exp show <id>` takes the experiment id that `eval run` prints for a tasks suite and lists its runs per task with the agent's cost at API prices. Before, it said the experiment was not found. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#the-report).
- **Refine.** When a `refine run --suite` climb holds a cheaper or faster candidate whose quality is even on average but whose interval is too wide to confirm within `--margin`, the round now says the hold is a sample-size problem ("the quality interval is too wide to adopt it within the margin at N tasks: add tasks or trials") instead of implying the gain cost quality, and carries a warning that names the quality lower bound against the margin and the fix. The verdict is unchanged; only the explanation is clearer. [How good is the hill-climb, really?](https://github.com/jackulau/coding.sh/blob/main/docs/research/hillclimb-quality.md).
- **Cost.** `usage` `TOK/TURN` (`tokensPerTurn`) divides only top-level sessions' tokens by their turns. Before, subagents' tokens were divided by their parents' turns, so a row with heavy subagents, or a model only subagents ran, showed an inflated or impossible tokens per turn. [Expensive sessions](https://coding.sh/docs/cost).

### Performance

- **Ingest.** The SQLite index gives each connection a 16 MB page cache (`cache_size`) and in-memory temp b-trees (`temp_store`), both bounded RAM freed on close, and ingest skips the duplicate `session_facets` inserts a session repeats across its events (the facet table is unchanged). Measured the paired way with `scripts/dogfood/bench.mjs ingest --baseline <dist>`. [Store ingest](https://github.com/jackulau/coding.sh/blob/main/docs/perf.md#store-ingest).

- **Harness A/B.** `compare --gate` answers "ship B or not": `Ship it: B wins 9 tasks, loses 0`, `Hold: not enough evidence`, or `Don't ship: B breaks 3 tasks A solved` with the broken tasks listed. It exits 0 only for "Ship it" (SAGE, arXiv 2609.36043). `--by suite:` gates each tagged suite too, and one broken suite blocks a pooled "Ship it". Each arm's failed runs are split by the agent's own last test run: `A fails 12: own tests green 7 (58%), red 3, stale 1, none 1`, where green fails are silent misses (BOBA, arXiv 2611.02207). `compare --promote` also keeps a B that is cheaper at the same quality: `pareto: support 0.93 ≥ 0.70 → promote (cost-cut: …)` or `→ hold`, exit 0 only on promote (ParetoSaddler, arXiv 2611.02079). No model calls (TestJack, arXiv 2610.10619). `--promote` adds it to the verifier, and `eval export`/`import` carry witnesses. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#witness-audits).
- **Harness A/B.** After `eval audit`, `compare` shows each audited arm's raw and audited pass rate, `audited pass  B 60% → 30% (3 refuted, coverage 100%)`. `--audited` counts refuted passes as fails and labels the verdict `verdict (audited)`, with a note when the audit changes it. It needs every pass in both arms replayed, or the raw verdict stands with a coverage note. `--json` and the MCP `harness_compare` tool add the per-arm counts. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#harness-ab).
- **Harness A/B.** `compare` adds a `surface` row: the bytes of instruction text each bundle puts in front of the agent (AGENTS.md and the other instructions files, skills, rules, system-prompt files, `~/` ones too). When B's is more than 20% bigger, a note asks for a success CI above 0 rather than a tie, since those bytes cost tokens on every turn. `--json` has the sizes per file in `report.surface`. [Compare agents](https://github.com/jackulau/coding.sh/blob/main/docs/how-to/compare-agents.md#4-read-the-result).
- **Evals.** Experiment sessions: `exp session new --name <topic>` starts one in a folder, and each `exp run` there prints its delta against the previous run on the same dataset as it finishes (`pass 0.0% → 100.0%  Δ +100.0pp […]  mcnemar p=0.125`, the grader deltas, the cases fixed and broken, the files changed), with no `exp compare`. `exp session note` records hypotheses and readings, `exp session summary [--json]` prints the timeline. `exp run --watch` reruns on every save of the spec, the agent script, grader files or `watch` globs, aborts a run made stale mid-way without storing it, and regrades the stored outputs with 0 agent calls when only the graders changed. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#sessions-deltas-notes-watch).
- **MCP.** `exp_session_note` adds a redacted note to the project's experiment session (the hypothesis before a run, the reading after it) and `exp_session_summary` returns its timeline, paged, with the same blocks as `exp session summary --json`, so an agent can pick an investigation back up after a context reset. Without a session both return a `not_found` error naming `coding.sh exp session new --name <topic>`. [Explore](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md#ask-your-agent).
- **Experiments.** `exp regrade <experiment> spec.json` grades a stored experiment's outputs again with new graders, without calling the task, and prints the pass rate before and after, each grader's version change and every run that flipped (`flips 1 of 4 runs: 1 pass → fail`). `exp compare` pins grader versions: a grader that changed version or graded one side only gets a warning above the verdict, and cases left ungraded on one side are listed. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#regrade).
- **Experiments.** `exp run matrix.json` runs a spec with `"matrix"` (JSON Pointer axes, every combination) or `"variants"` (named cells plus `"vary"`) against a baseline cell: the cells run interleaved, each is stored as its own experiment with `metadata.matrix`, each is compared with the baseline, and the McNemar p-values are Holm-adjusted over the cells. A cell that differs from the baseline outside `vary`, or touches graders or the dataset, is refused before any call; `--plan` prints the cells and runs nothing, `--cell` runs a subset, `--resume` continues an interrupted matrix. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#matrix).
- **Graders.** The `agent-slop` grader flags placeholder code, `as any` and `@ts-ignore`, empty catches, leftover debugging, focused or skipped tests and narrating comments in the lines an agent's diff adds, and `coding.sh judge slop <session|run|experiment>` scores captured work with it, per arm for a compare experiment. Verifiers get the agent's diff in `CODING_SH_AGENT_DIFF`. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#agent-slop).
- **Query.** `coding.sh sql "select …"` runs one read-only SQL query against the SQLite index: one `SELECT` or `WITH` statement on a read-only connection with `query_only` on, with a timeout (`--timeout`, 10 s) and a row cap (`--limit`, 1000). Writes, `ATTACH`, `PRAGMA` and a second statement exit 2; Postgres and ClickHouse stores get an error that points to `export`. `coding.sh export sessions|events|labels` streams rows as JSONL or CSV with the same filters as `sessions`, on every store. [Query and export](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md).
- **Privacy.** Sessions count what redaction replaced, by kind, in `stats.redactions` (counts only, never values; blobs and metadata mode included), and a session in which a vendor token was redacted gets the `secret:exposed` tag, since the agent and its model provider still saw it. `coding.sh sessions --flag secret:exposed` lists the credentials to rotate, and `show` prints a `Redacted` row. Sessions stored earlier are counted from their redaction markers. [Storage, sinks and privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md).
- **Privacy.** `coding.sh purge --literal <file>` removes a leaked secret from the SQLite store after the fact: event payloads and the search index, session titles and stats, labels, eval docs, settings, blobs (rewritten under a new hash, with references repointed) and the spool, then VACUUMs the index. Values come from a file or stdin and are never printed; `--dry-run` counts the copies. [Storage, sinks and privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md).
- **Cost.** `coding.sh usage` marks a cost that counts only some of a row's sessions as a lower bound (`≥$1.50`, replacing the `+` suffix), prints how many sessions have tokens but no cost, and names up to five unpriced models with the `[prices."<model>"]` fix. `--json` is unchanged. [Find expensive sessions](https://coding.sh/docs/cost).
- **Experiments.** `compare A B --reuse baseline` copies A's finished runs from earlier comparisons instead of running them again (`--reuse both` copies B's too), so several candidates against one baseline pay for it once. A run is reused only when its task, verifier and hidden files, bundle, agent version, attempt, timeout and route hash the same, it finished without an error, and it is newer than `--reuse-max-age` (default 7d). `--dry-run` prints how many runs each arm would reuse and run, and the report notes that reused runs did not run interleaved. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#reuse-finished-runs).
- **Evals.** An `executability` grader scores a run by how far it got before its first invalid tool call, one the harness refused to run (a bad argument, an unknown tool, an edit of a file not read yet, a string to replace that is not there, a missing file or command, a denied call). A test that exits 1 ran and is not invalid. The score is the share of steps before that call (its mean is AUC-PEC), and it passes with at most `maxInvalid` invalid calls (its pass rate is TER); `kinds` counts only some kinds (Prefix Executability, arXiv 2610.40444). [Explore guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md#executability).
- **Query.** `sessions`, `search`, `usage` and `export` take `--where`, one filter language over any session or event field: `agent:codex cost>0.5 tool:Bash ok:false -flag:compaction`, with `OR`, `( )`, wildcards, ranges, `sort:` and `limit:`. `sessions --facets model,tool` counts sessions per value. The viewer API (`?where=`, `/api/facets`) and the MCP tools `sessions_list`, `search` and `usage` (`where`, `facets`) take the same queries. On SQLite a query is one parameterized SQL statement; a typo is a usage error that points at the character. [Query and export](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md#filter-with---where)
- **Query.** `--where` on tools, MCP servers, event kinds and `ok` reads indexes instead of scanning events, and their facet counts come from a small per-session table. On a 3.3 GB, 1.4M-event store, `tool:Bash ok:false` takes 5 ms instead of 26 s and the tool, MCP and kind facets 31 ms instead of 8.5 s. The store migrates once on open (about a minute at that size, +4% on disk). `GET /api/events` returns matching events across sessions, newest first and keyset-paged, and `/api/facets` takes `prefix` for autocomplete. [Query and export](https://github.com/jackulau/coding.sh/blob/main/docs/reference/query.md#filter-with---where)
- **Viewer.** The session list has one filter bar for the `--where` language: it completes keys and values (with session counts), runs as you type, and on Enter says what is wrong with a bad query and where. Clauses show as removable chips. The sidebar counts sessions per agent, model, repository, branch, flag, tool, MCP server and event kind; a click adds a value, Alt-click excludes it, and groups fold shut. The query is in the URL, and old `?agent=` and `?q=` links still open. Full-text hits moved out of the list; the list matches sessions by their text. [Explore](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md#open-the-viewer)
- **Viewer.** An Events tab next to Sessions lists the events that match the query, newest first, with the session each belongs to and the matched words marked. Enter opens the event's step in its session, and `n` and `N` step through that session's other matches. `GET /api/events` takes `scope=top`. [Explore](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md#open-the-viewer)
- **Privacy.** `coding.sh purge --rule <regex>` removes every match of a secret's shape (`sk-ant-api03-[A-Za-z0-9_-]{80,}`) the way `--literal` removes a value, without printing the rule or a match. Purge also scrubs eval run dirs (`~/.coding.sh/runs`), where a kept run holds the agent's transcripts. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md)
- **Experiments.** `exp run matrix.json --reuse baseline` copies the baseline cell's finished case-trials from earlier experiments instead of running them again, so several matrices against one baseline pay for it once (`--reuse all` copies any cell's). A case-trial is copied only when its case, task spec and files, graders, trial number and timeout all match, within `--reuse-max-age` (default 7d). `--plan` prints how many each cell would copy, and the comparisons warn that the copies did not run interleaved. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#matrix).
- **Compare.** `compare A B --experiment <id> --retry-errors` runs again, in place, only the runs of a stored comparison that errored or failed on infrastructure, and each task, arm and attempt counts once. `--failing <id>[@bundle]` runs only the tasks A failed in that comparison, with a note that the pass rates are conditioned on that failure. `--sample N --seed S` runs a seeded random sample of the tasks. `--json` adds `planned`, `skipped`, `retried` and `selection`, and the consent prompt counts only the runs still to go. [Evals guide](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#iterate-on-a-comparison).
- **Docs.** A grader field reference: every grader kind, its fields and defaults, and when it passes, with the provider fields judges share. [Grader fields](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#grader-fields)
- **Experiments.** `exp ab` and `refine` run on a Claude or ChatGPT subscription with `--provider claude-code` (`claude -p`) or `--provider codex` (`codex exec`), and pick one on their own when no API key is set and the CLI is logged in, saying so in one line. Each call runs without your hooks, plugins, MCP servers or settings, in a throwaway config dir; with `claude -p` the model gets the session's own Claude Code tools and a hook of ours refuses every call, so none runs. Calls run 2 at a time, rate limits back off and retry, and a spent usage limit stops the run with the finished trials kept. Costs show as API-equivalent, with no cap unless you pass `--max-cost`; `improve` and `improve fix` suggest the test on a subscription too. [Replaying on a subscription](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#replaying-on-a-subscription).
- **Judges.** LLM graders take `"provider": "codex"`, which grades through `codex exec` on a ChatGPT subscription. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#judges).
- **Experiments.** `exp ab` with no uncommitted harness edits tests your last commit that changed AGENTS.md, a rule or a skill against the version before it, `--dry-run` included, instead of stopping with "No uncommitted changes". [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#ab-a-harness-edit-on-your-own-sessions).

Before, comparing a full `~/.claude` against plain Claude Code printed one line per file, 1,500 of them. `--json` still lists every path in `report.bundleDiff`. Old links to a section that moved still land on it. [CLI reference](https://coding.sh/docs/cli)

Counting the 27 sessions that stayed on the requested model, graded with the fixed site check, 0/14 runs passed without the skill and 9/13 with it (+69.2 points, 95% CI +23.1 to +100, McNemar p = 0.25, gate Hold), at 6 times the cost per run. - **Experiments.** The item gate no longer accepts removing a skill or rule when the agent fails the exposed tasks without it; such items read UNCOVERED (neither arm solves them) or UNMEASURED (pass rate without the item under 0.8). The gate line shows `U=` and `A=` and a count of internalized, works, uncovered, hurts and between tasks (Wang et al., arXiv 2610.32322). ### Fixed

- **Sessions.** Replay knows that a file a step created did not exist before that step, instead of calling it unknown, so `replay --fork --run` removes it from the fork's copy. [Replay a session](https://coding.sh/docs/use-cases/replay-agent-session#how-files-are-rebuilt).
- **Evals.** `eval validate` applies a reference or near-miss patch after setup when it only applies to what setup creates, as an agent's run sees it. Before, a task whose setup made the mess the agent cleans up could not validate: its reference "did not apply". [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#hand-written-tasks).
- **Improve.** `improve check --repo <DIR|all>` counts the sessions that ran in other checkouts and worktrees of the repo. Before, it ignored `--repo` and counted only sessions whose repo root was the current checkout, so a repo whose agents work in worktrees showed every change as "No sessions yet". [Improve](https://github.com/jackulau/coding.sh/blob/main/docs/guides/improve.md).
- **Harness.** `harness audit` skips a file or directory it can't stat (a symlink loop, or a Windows junction Node can't follow) instead of failing with "unknown error". [Memory and instruction files](https://github.com/jackulau/coding.sh/blob/main/docs/guides/explore.md#memory-and-instruction-files).
- **Harness A/B.** `harness snapshot` follows linked skill, command and agent directories (`npx skills`, a dotfiles repo) and stores the files they point to. Before, a `~/.claude/skills` made of links snapshotted no skills, so the arm ran without them. [Harness A/B](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#harness-ab).
- **Harness A/B.** `compare` and `eval run` say why a failed run's agent failed: its exit code or timeout and the last lines of its stderr, redacted, under the report and in `failedRuns[].agent`. Before, an agent that couldn't start (Claude Code refusing bypass permissions as root, a bad flag) failed every run in seconds with only the verifier's output shown. [Verifier output](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#verifier-output).
- **Capture.** Backfill follows symlinked and junctioned transcript directories and files, and skips dangling links. Before, a `~/.claude/projects` made of links ingested nothing. [Adapters](https://github.com/jackulau/coding.sh/blob/main/docs/ADAPTERS.md#known-breakage-to-design-around).
- **Harness A/B.** Two tasks from the same repo no longer error when they start at once: the first run of a repo set up its snapshot store while the second was reading it. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md).
- **Harness A/B.** The tamper check no longer flags a run that only added new test cases to an existing test file, so a regression test written next to the fix keeps the task in the gate's evidence. Changed, removed or skipped tests, early returns, hooks, mocks and shadowing definitions still flag. The run lists those files in `tamper.addedTests`. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#harness-ab).
- **Sessions.** `premature-completion` no longer flags an agent that stopped on a failing test run and said so ("2 tests still fail", "I couldn't get test_x to pass", or a question about the failing test). It still flags one that says it is done, fixed or passing, or says nothing about the failure. Stored sessions get their flags recomputed once. [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Site.** A page that shows "±" no longer downloads a second font file for it. [Site speed](https://github.com/jackulau/coding.sh/blob/main/docs/perf.md)
- **Harness A/B.** `compare --gate` no longer says "Don't ship: B breaks a task A solved" when both arms passed it by editing tests. Tamper-flagged passes now count as fails for the gate in both arms, not only in B. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#harness-ab).
- **Experiments.** `exp ab` with no `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` stops before the first trial with `missing_key` and points at `coding.sh improve check`, instead of running every case into an error and reporting "Hold: not enough evidence". `refine propose` without a key names the proposer, not the judge. [Improve your agent every week](https://github.com/jackulau/coding.sh/blob/main/docs/guides/improve.md#test-it-before-you-commit).
- **Rules.** An AGENTS.md line like "Run `npm test` before you say you are done, and never claim…" is read as a requirement to run `npm test`: the clause that holds the command decides, not a "never" later in the line.
- **Judges.** The Anthropic and OpenAI judge providers read `ANTHROPIC_BASE_URL` and `OPENAI_BASE_URL`, like the vendors' SDKs, so judges and drafts reach a proxy, gateway or local stub without `--base-url`. [Judges](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#judges).
- **Experiments.** When no attempt in either arm solves a task, `compare` suggests `coding.sh eval validate <task>` instead of an `eval curate` command that does not exist.
- **Refine.** `refine check`, `refine test` and `exp ab` judge only the new sentences of an edited line when looking for an edit that relaxes a protected line. Editing a one-line paragraph that already held a conditional ("use the CLI only if …") no longer rejects the edit. [Protected safety lines](https://coding.sh/docs/harness-evals#protected).
- **Examples.** The skill eval's live site check counts a network command that uses `$LIVE_SITE` as touching the site; it missed those, and passed runs that had probed the site. Scenario 06 no longer tells the agent to record open questions instead of waiting, since its pass is to stop and ask. [Skill eval example](https://github.com/jackulau/coding.sh/tree/main/examples/skill-eval#live-run-a-real-vercel-team-read-only).
- **Privacy.** `coding.sh purge` never repeats what was typed on its command line: a secret pasted as an argument, a flag value, an unknown option or a `--literal` path that does not exist is refused with exit 2 and `(value not shown)`, instead of being printed to the terminal and logs. Other commands still name a stray argument. [Purge](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md#codingsh-purge).
- **Compare.** The `agent spend` and `grader spend` rows no longer count runs copied by `--reuse`; a `reused` row shows what those runs cost when they first ran, marked not spent. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#reuse-finished-runs).
- **Sessions.** Claude Code subagents get a title and a turn: the title is the Agent tool's `description`, else the first line of the prompt, and the prompt is recorded as the subagent's first message. Claude Code's internal forks (the compaction summarizer, prompt suggestions) no longer leave empty subagent sessions with no model, tools or title. Stored sessions are parsed again on the next ingest. [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Capture.** Claude Code subagents that fire no SubagentStart or SubagentStop (`web-fetch`) are linked to their parent from the parent's `Agent` tool result, with their prompt, result, model and end, instead of showing as a top-level session with no prompt. [Adapters](https://github.com/jackulau/coding.sh/blob/main/docs/ADAPTERS.md#subagents).
- **Sessions.** `skill:<name>` tags and `skill-copy-conflict` count only installed skills: a `skills/` folder under an agent's dot folder or in a plugin. A `skills/` folder in source code (`skills/mod.rs`), a reference checkout, text inside a heredoc and a write to a skill file no longer tag a skill. Codex's `.system/` and `synced/<id>/` folders are skipped, so `skill:.system` and `skill:synced` become the skill's own name, and a plugin named for its one skill is tagged once (`skill:frontend-design`). [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Sessions.** `test-tamper` no longer flags adding tests: a skip guard inside a new test, fixing a test the agent added earlier, updating an expectation its own source edit broke, or a green run of fewer tests than the failing one. A file a shell command's diff picked up without the command naming it (a test run, a `git rebase`, another agent in the checkout) is never flagged, and BSD `sed -i ''` no longer counts `''` as a file. A skip marker inside a string literal (a diff or `sed` command a test holds as data) is not a skip. Stored sessions are re-checked in the background after the upgrade. [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md).
- **Sessions.** `coding.sh sessions` leaves out sessions with no turn, tool call or model call, such as a process that started and ended a session and did nothing; `--empty` lists them too, and `--limit` still fills with sessions that have work. [CLI reference](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md).
- **Cost.** `usage` `TOK/TURN` (`tokensPerTurn`) is input, output and cache-write tokens per user turn. Cache reads are left out, because each model call re-reads the whole context, and `TURNS` counts only top-level sessions' turns, because a subagent's prompt comes from its parent's turn. [Expensive sessions](https://coding.sh/docs/cost).
- **Capture.** The background re-parse after an upgrade no longer blocks reads: it holds the ingest lock at most a second at a time and ingests new hook lines between holds, so `sessions` and the viewer answer in about a second instead of waiting 8 to 24 seconds. It writes blobs in batches, resumes where a cut-short run stopped, and works out stats and flags again for every stored session when an upgrade changes them. Listing a large spool is faster too. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md#old-sessions-show-doubled-counts).
- **Doctor.** Hooks in a project's config (`.claude/settings.local.json`, `.codex/hooks.json`, `.gemini/settings.json`, `.cursor/hooks.json`, …) show as `hooked in <file> (project)`, found in the current directory and in the directories the agent's recent sessions ran in. An agent with events in the last 5 minutes and no hook found reads `events arriving, hook not in user config`, never `not hooked`. A stale hook bin now says `run coding.sh update --refresh-bin` instead of `init`, and `coding.sh ingest` (which the hook starts at every session end) refreshes the bin itself after `npm i -g` of a newer version. [Troubleshooting](https://github.com/jackulau/coding.sh/blob/main/docs/troubleshooting.md).
- **Viewer.** API sessions with a failed request are red in the session list again, with the reason: `1 failed request (429)`, the first error on hover. Sessions carry `stats.llmErrors`, counted at ingest (existing indexes are filled in on upgrade), and a list page costs the same store queries at any length.
- **Viewer.** The top bar fits from 320px up, in any font (on Linux without Geist it ran 2px past a 320px screen; a tab label now ends in an ellipsis before the page scrolls sideways): between 641 and 820px search folds to its icon instead of squeezing the theme button, and every top bar control has a 44px hit area.
- **Viewer.** The session title in the list keeps at least 12rem on any desktop width (at 1024px, next to the filter sidebar, it was 20px): tokens, then duration, then repo, then activity give way first.
- **Windows.** `coding.sh update` and the MCP launcher run npm and `coding.sh` without a shell, so paths with spaces or `&` arrive intact.
- **Windows.** Goose's config is found under `%APPDATA%\Block\goose\config`, where Goose keeps it on Windows. Eval runs find agent binaries on PATH (Windows spells it `Path`), and Amp and Pi hooks use the `node` on PATH, as elsewhere, instead of the one that ran `init`.
- **Aider.** Eval runs pass `--no-show-release-notes`: on a new version's first run, `--yes-always` made aider open its release notes in a browser.
- **Codex.** Code mode: a command run inside an `exec` cell now points at the cell, the cell fails when a command in it fails, and session stats count each command once instead of twice (hooks and backfill agree).
- **Viewer.** A big ingest no longer blanks reads: `coding.sh ui` opens at once (0.3 s, was 41 s on a 25k-line spool) and indexes in a background worker with an "Indexing N files…" pill, and `status`, `sessions` and `search` answer within 1.5 s, noting what is still pending (`--fresh` waits). [CLI reference](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md).
- **Capture.** A full ingest of a 25k-line spool takes 4 s instead of 294 s on macOS, and 39 s instead of 153 s on Linux: blobs are made durable once per checkpoint instead of with two fsyncs per line, and each checkpoint commits its events, session rows and spool cursors in one transaction, so a crash mid-drain neither loses nor duplicates events.
- **Cost.** `coding.sh collector` prices model calls with tokens and no cost, as `serve` and `ingest` do, using your `[prices]`.
- **Viewer.** The top bar fits a 360px phone.
- **MCP.** Tool calls no longer wait for a big ingest: they answer within 1.5 s from what is indexed, with `pending: {files, indexing}` in the result. [CLI reference](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md#codingsh-mcp).
- **Harness A/B.** `compare` and `eval crosscheck` runs keep the agent's text from mid-turn: the run dir, which holds the agent's own transcript, was removed before it was ingested, so the session kept only the final reply.
- **Examples.** The skill eval's live mode grades fairly: `--help` and `help` calls never count as writes, a refused `env ls` reads "refused secret read", live task copies name the team, project and site only through `$VERCEL_SCOPE`, `$VERCEL_PROJECT` and `$LIVE_SITE`, the site checks match the team's real domains (kept from the agent), and `out/checks` records each run's task and arm. `run.sh <out-dir> --regrade` grades stored runs again without calling the agent. [Evaluate an Agent Skill](https://coding.sh/docs/how-to/evaluate-a-skill#2-stub-what-the-skill-touches).
- **CLI.** `status`, `sessions` and `search` with `--json` carry `"pending": {"files", "indexing"}` while captures are still waiting, instead of dropping the note. [CLI reference](https://github.com/jackulau/coding.sh/blob/main/docs/reference/cli.md#codingsh-status).
- **Evals.** A command task, grader or source that crashes names the error and its cause, such as `exited 1: TypeError: fetch failed (cause: connect ECONNREFUSED 127.0.0.1:8803)`, instead of the last three lines of stderr (for Node, the closing braces of the error object). A refused connection now reads as an infrastructure error, so the trial is retried and counted as infra, not as a failure. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Evals.** A task drafted from a session names the files its setup was guessed from, such as `setup guessed from package.json (no lockfile): npm install`, instead of saying "from lockfiles" when there was none.
- **Experiments.** A grader error leaves a run ungraded only when no other grader failed it. With `exact` and a judge that is down, the runs `exact` failed count as failures and only the runs it passed are left out, instead of every run reading ungraded and the pass rate going blank. `exp regrade` follows the same rule. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Evals.** `eval run` reports on a cases suite say "case" and on a triggers suite "prompt" (the header, the table, never-passed, saturation and the regression lines), and `--json` carries the report's `unit`.
- **Evals.** `eval validate` shows the last 12 lines of the verifier's output when a check goes the wrong way (the reference fails, the no-op or a near-miss passes, or setup fails), once per kind of check, and `--json` carries every step with its output in `steps`. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Evals.** `eval init --force` no longer deletes your work: it stops when the suite holds a file `eval init` did not write or that you changed since (a `reference.patch` you added, a prompt you fixed) and lists them. `--force-all` deletes those too. `evals/<name>/.eval-init.json` records what `eval init` wrote. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#your-agents-failed-sessions)
- **Evals.** `eval init --skill <dir>` uses the skill's own `triggers.toml` when it has one and you give no prompts and no `--draft`: `suite.json` points at it instead of a TODO template. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#a-skill)
- **Evals.** `eval init --sessions` and `--session latest` include a session that just ended: they wait up to 30 seconds for the ingest its hook started, then ingest the rest, instead of skipping the ingest when its lock is busy after 1.5 seconds. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#your-agents-failed-sessions)
- **Graders.** When a command grader, command task or bench source crashes on Node 24.22, its reason names the error again (`TypeError: fetch failed (cause: connect ECONNREFUSED …)`) instead of the crash's closing braces. Node 24.22 prints an uncaught fetch failure as `[TypeError: fetch failed] {`. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md)
- **Store.** A SQLite index that fails to open (a newer schema, a failed migration) no longer stays open in the process that tried, so on Windows the file can be replaced or removed right away. [Concepts](https://github.com/jackulau/coding.sh/blob/main/docs/concepts.md)
- **Evals.** On Windows, `eval init` and `eval run` show suite paths with forward slashes, like the file list under them: `Wrote … to evals/triage`, `evals/pdf/triggers.toml still say TODO` and the `--skill` path in the `--draft --force` hint read the same on every OS. [Evals](https://github.com/jackulau/coding.sh/blob/main/docs/guides/evals.md#a-skill)

## [0.1.1] - 2026-11-07

Daily benchmarks for any AI agent: `coding.sh bench` runs every contender on fresh cases each day,
and experiments add cluster bootstrap, an A/A noise floor, interleaved runs, early stopping and `compare --without`.
Seven more agents are verified on a real install, the viewer and the site work on phones, and the installer uses npm once the package is there.

### Added

- **Benchmarks.** `coding.sh bench` samples fresh cases each day from a command, failed sessions, GitHub issues, a sitemap or a dataset, freezes them as a dataset version and runs every contender on that set in random order. [Benchmarks](https://github.com/jackulau/coding.sh/blob/main/docs/guides/benchmarks.md).
- **Benchmarks.** Shared timeout and retries, a budget cap, quota and rate-limit cases dropped for every contender, and `bench run --resume` to finish a stopped run with the same seed and cases.
- **Benchmarks.** `bench report` writes a static HTML page and JSON: trend, gaps to a reference pooled over a fixed window, head-to-head stats, difficulty and failures. `bench regrade` re-scores stored outputs and `bench schedule` prints a cron line and a GitHub Actions workflow.
- **Benchmarks.** An `[anchor]` set of fixed cases runs every day next to the fresh ones and is scored apart, so its trend has no day-to-day difficulty in it.
- **Benchmarks.** `seed = "secret"` publishes the hash of each next day's salt and `bench show` checks the chain. Content hashes keep the same case under a new key from counting as fresh.
- **Benchmarks.** Input and output tokens are kept apart, and each cost says where it came from: reported, `costPerRun`, the shared price table, or unknown.
- **MCP.** A `benchmarks` tool lists benchmarks and reads results and history.
- **Experiments.** `exp compare --cluster <key>` resamples by repo or session and warns under 10 clusters. [Evals](https://coding.sh/docs/evals).
- **Experiments.** `exp aa` measures the run-to-run noise floor, and power planning uses it.
- **Experiments.** Compare flags uneven attrition between arms (Fisher exact) and splits infra errors from agent errors.
- **Experiments.** Under 100 paired cases, compare also reports P(B>A) from a paired posterior.
- **Experiments.** `exp run --arm a=<task> --arm b=<task>` interleaves both arms case by case in a seeded random order.
- **Experiments.** `--stop-early` checks at planned looks with O'Brien-Fleming alpha spending and reports a repeated confidence interval.
- **Experiments.** Pairwise judges see both outputs in both orders. `exp compare --pairwise` reports win rate, ties and position bias.
- **Experiments.** `exp sweep` races task configs on a train split and reports the winner's optimism gap on held-out cases.
- **Compare.** `compare <bundle> --without <path>` measures what one skill, AGENTS.md or MCP config is worth. [Compare agents](https://coding.sh/docs/how-to/compare-agents).
- **Compare.** With 2+ attempts per task, failed runs split into bad runs, arm limits and tasks no arm solves, with variance shares.
- **Compare.** Cost rows show how many runs had a known cost, and "cheaper" needs a known cost for 80% of each arm.
- **Agents.** Verified on a real install against a local stub model: opencode, copilot-cli, droid, goose, pi, t3code and aider. [Agent matrix](https://coding.sh/docs/agents).
- **Agents.** Antigravity backfill reads agy transcripts and conversation DBs for model, tokens, cache reads and latency per call. Tool steps missing from the transcript count as failures, and hooks reply `{}`.
- **Viewer.** Phone layouts: 44px targets, filters in a bottom sheet, a compact session header and safe-area insets.
- **Viewer.** The Benchmarks tab shows anchors, pooled gaps, difficulty, cost sources and tokens, and ranks follow the pooled gaps.
- **Site.** Mobile pass: touch targets, safe areas, stacked agent cards and 16px body text on phones.
- **Site.** A new landing page, a changelog page and docs pages.
- **Install.** `install.sh` installs from npm when the registry has the version, else from the GitHub release. `CODING_SH_SOURCE=npm|github` picks one.
- **Release.** A tag creates its GitHub release as soon as the checks pass, so the installer gets it right away.
- **Release.** The release workflow can publish all five packages to npm and PyPI with trusted publishing. Nothing is on npm or PyPI yet.
- **Docs.** A new README, reference pages, how-to guides and a code of conduct.

### Fixed

- **Fixes.** Safer installs: symlinked and JSONC agent configs survive, `init --dry-run` prints a short plan, and blockers show before the Y/n.
- **Fixes.** Each SQLite migration runs once when the hook and the CLI open a new index at the same time.
- **Fixes.** Experiments stop cleanly on Ctrl-C, kill their child processes and keep every finished run.

## [0.1.0] - 2026-11-06

The first public release, still pre-1.0. coding.sh records what your AI agents do, with coding
agents first-class, on your own machine, shows it in a local viewer, and turns those sessions into evals and A/B experiments.
It also runs as a server on SQLite or Postgres, with SDKs for apps that call model APIs.

### Added

- **Install.** `curl -fsSL https://coding.sh/install | sh` checks for Node 22.15+, installs with npm, runs `init` and opens the viewer.
- **Install.** Or `npm install -g coding.sh && coding.sh init`. `init` shows one plan and asks one Y/n. [Install guide](https://coding.sh/docs/install).
- **Install.** `coding.sh` with no command opens the viewer, and sets up capture on its first run.
- **Install.** Commands print one dim line when a release is out, checked in the background at most once a day.
- **Install.** `coding.sh update` installs the new release. The check is off in CI and [can be turned off](https://github.com/jackulau/coding.sh/blob/main/docs/guides/install.md).
- **Install.** `coding.sh uninstall` restores each agent config byte for byte if nothing else has edited it since.
- **Capture.** Hooks record prompts, tool calls, file changes, turns and errors to a local spool, then ingest them into sessions.
- **Capture.** Secrets are redacted before anything is stored. [Privacy](https://github.com/jackulau/coding.sh/blob/main/docs/guides/privacy.md).
- **Capture.** `run` spools secret flag values (`--openai-api-key X`, `--api-key=X`) redacted, and ingest redacts them in any argv.
- **Capture.** Pi, Goose, Copilot CLI, Droid, Gemini CLI and Antigravity sessions seen by hooks and by `ingest --backfill` store each call, reply and turn once, and count tokens once.

- **Cost.** A model call nested in another, or a repeated response id, counts once in session totals.
